🎮 数学キャッチゲーム

Math Catch Game - Powered by Rust + WebAssembly

HP: 100%
スコア: 0
残り時間: 60s

🎯 遊び方

💻 PC操作

  • 移動: WASD / 矢印キー
  • 左: A, Q, Z, ← (Gより左のキー)
  • 右: D, H〜M, → (Hより右のキー)
  • 上: W, Q列キー, ↑
  • 下: S, Z列キー, ↓
  • 網回転: スペース / Enter (30度ずつ)

📱 スマホ/タブレット操作

  • 移動: 左下の十字ボタン
  • 網回転: 右下の🔄ボタン

📋 ゲームルール

  • ✅ 指示された数字を網で捕まえてください
  • 💚 正解: +100点
  • 💔 不正解: -20 HP（0になるとゲームオーバー）
  • 🎁 問題クリア: +200点 + HP回復(+30)
