# 数学キャッチゲーム (Math Catch Game)

Rust + WebAssembly で実装された、数学を楽しく学べるアクションゲーム！

## 🎮 ゲーム概要

浮遊する数字を網で捕まえながら、数学の問題を解いていくゲームです。楽しみながら数学力が身につきます。

## ✨ 特徴

- **Rust + WebAssembly** による高速で安全な実装
- **2D Canvas** を使った滑らかなアニメーション
- **数学問題のバリエーション**: GCD (最大公約数)、LCM (最小公倍数)、約数、素数など
- **直感的な操作**: クリック/タップで網を伸ばして数字をキャッチ
- **自動回転する網**: 30度ずつ回転する網でタイミングを計って捕獲

## 🎯 遊び方

1. **ゲーム開始**: 「ゲーム開始」ボタンをクリック
2. **網の操作**: 画面をクリック/タップすると網が伸びます
3. **数字を捕獲**: 回転する網のタイミングを見計らって、正しい数字を捕まえます
4. **スコア獲得**: 
   - 正解の数字: **+100点**
   - 不正解の数字: **-50点**
   - 問題クリア: **+200点**

## 🧮 数学問題の種類

### Phase 1 (現在実装済み)
- **GCD (最大公約数)**: 2つの数の最大公約数を見つける
- **LCM (最小公倍数)**: 2つの数の最小公倍数を見つける
- **約数**: 指定した数のすべての約数を集める
- **素数**: 画面上の素数をすべて集める

### Phase 2〜7 (将来実装予定)

- 放物線、楕円、双曲線
- アイテムシステム
- ローカル2人プレイ
- ミニゲーム
- ガチャ＆コレクション
- オンライン対戦

## 🚀 開発環境セットアップ

### 必要な環境
- Rust (1.92.0 以上)
- wasm-pack
- Node.js / npm (オプション)
- モダンブラウザ (Chrome, Firefox, Safari, Edge)

### ビルド方法

```bash
# Rustプロジェクトをビルド
wasm-pack build --target web

# 開発サーバーを起動
python3 -m http.server 8000

# ブラウザでアクセス
# http://localhost:8000
```

## 🎨 ゲームシステム

### プレイヤー
- 画面中央に配置
- 青い円で表現
- 網を30度ずつ自動回転

### 網システム
- クリック/タップで伸びる
- 赤い回転インジケーター
- 黄色の網で数字をキャッチ

### 数字オブジェクト
- ランダムに移動
- 壁で反射
- 正解: 青緑色
- 不正解: グレー
