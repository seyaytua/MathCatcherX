# 数学キャッチゲーム (Math Catch Game)

**Version: 0.4.0**

Rust + WebAssembly で実装された、シンプルで楽しい約数学習ゲーム！

## 🎮 ゲーム概要

指定された数の約数を見つけてクリック/タップするシンプルなゲームです。

## ✨ 特徴

- **Rust + WebAssembly** による高速で安全な実装
- **シンプルな操作**: クリック/タップのみ！
- **約数問題**: 数学の基礎を楽しく学べる
- **5×4グリッド**: 20個の数字から正解を探す
- **タイマー制**: 60秒間のスリリングなゲームプレイ

## 🎯 遊び方

1. **ゲーム開始**: 「ゲーム開始」ボタンをクリック
2. **問題を確認**: 「○○の約数を見つけよう」と表示されます
3. **数字をクリック**: 正しいと思う数字をクリック/タップ
4. **スコア獲得**: 
   - 正解: **+100点**
   - 不正解: **-20 HP**
   - 全問正解: **+200点 + HP回復(+30)**
5. **時間制限**: 60秒以内にできるだけ高得点を！

## 📱 対応デバイス

- **PC**: マウスでクリック
- **スマホ/タブレット**: タップ操作
- **すべてのモダンブラウザ**: Chrome, Firefox, Safari, Edge

## 🧮 数学問題

### 約数問題
指定された数のすべての約数を見つけるゲームです。

**例**: 「12の約数」
- 正解: 1, 2, 3, 4, 6, 12
- 不正解: 5, 7, 8, 9, 10, 11, 13〜

## 🎨 ゲームシステム

### スコアシステム
- **正解**: +100点
- **不正解**: -20 HP
- **問題クリア**: +200点ボーナス
- **HP回復**: 問題クリア時に +30 HP

### HPシステム
- 初期HP: **100**
- 不正解でダメージ: **-20 HP**
- HP が 0 になるとゲームオーバー
- 問題クリアで回復: **+30 HP** (最大100まで)

### タイマー
- 制限時間: **60秒**
- 時間切れでゲームオーバー

### 数字の配置
- **5×4 グリッド**: 合計20個の数字
- **青緑色**: 正解の数字
- **グレー**: 不正解の数字
- クリック/タップ済みの数字は非表示

## 🎮 ゲームプレイのコツ

1. **約数の見つけ方**
   - 1 と その数自身は必ず約数
   - 小さい数から順番にチェック
   - 割り切れる数が約数

2. **スコアを稼ぐ**
   - 正解だけをクリック
   - 間違えるとHPが減る
   - 時間を意識して素早く判断

3. **HPを維持する**
   - 確実に分かる数字から選ぶ
   - 問題をクリアしてHP回復
   - 時間に余裕を持つ
